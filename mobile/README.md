# CookandPin for Expo

Expo companion app for the existing Cook & Pin Android recipe catalog. The original Java Android source remains in `../app/`.

This first port includes the nine recipes currently in the Android source, recipe search, detail views, and serving estimates. It does not yet port native notifications or persistent saved recipes.

Run `npm install` then `npm start` from this directory. The Expo project is `@finalpages-team/cookandpin`. Build the Android preview APK with the `preview` EAS profile.
